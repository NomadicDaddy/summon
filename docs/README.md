# Summon documentation

Start with [your first team and teammate](getting-started.md). The guides below follow ordinary
operator tasks; detailed command and implementation constraints remain in the reference pages.

## Everyday tasks

- [Give work and follow progress](guides/work-with-your-team.md): Room replies, private mail,
  statuses, Board and Diary.
- [Choose a control](guides/control-work-and-decisions.md): decisions, Hold Interruptions,
  communication halt, head-down, rest, hibernation and Stop.
- [Maintain teammates and conversations](guides/manage-teammates.md): profiles, saved sessions,
  provider accounts and integration limits.
- [Back up, update and remove Summon](guides/maintain-your-installation.md): application files,
  team data, updater recovery and uninstall.
- [Diagnose startup and delayed notices](guides/troubleshoot-startup-and-delivery.md): recorded
  evidence, unread work and refusals without blind replay.
- [Use the Team Board](guides/team-board.md): lanes, blockers, owner notifications and archive.

intended for the operator's terminal and commands intended for named teammates have different
authority; a role, status or read receipt does not grant permission.
