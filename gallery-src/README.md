# Gallery icon sources

One SVG per starter in the Add teammate gallery. Each is drawn on a 128 x 128 viewBox, and
`gallery/<id>.png` is that SVG exported at exactly 128 x 128 (RGBA). Summon copies a starter's PNG
to a new member's avatar when the member is created from it.

These sources are tracked so the icons can be redrawn and re-exported. They are not packaged.

The style, kept the same across all fourteen so they read as one set at the roster's 32 px:

- A rounded `#0b1220` tile, 36 px corner radius, transparent outside it.
- A line glyph in `#87d6b2` with a 10 px stroke and round caps and joins, inside the central 80 x 80.
- Exactly one element in gold `#d9a441`, and no letters.

Drawn for Summon by Vera to Jimmy's brief, 2026-10-04, and part of Summon under its licence. The
ADHD coach and healthcare advocate icons were drawn by Jimmy in the same style on 2026-10-05.
