Delivery

On, Claude confirms the channel at every start, and notices queue for it while it runs rather than waiting for a checkpoint. Off, there is no prompt and notices are read at startup and at each checkpoint. Neither mode interrupts work already in progress. Either way the change applies the next time a Claude teammate starts, never to a session already running.

Interruptions

On, selecting a running teammate or typing at them holds their automatic interruptions for the countdown, which restarts as you type. Off, nothing is held until you press Hold Interruptions. Switching to another window never starts the countdown.
